# Security policy

damage-control-dev is a seatbelt for AI coding agents, not a sandbox. See
`docs/threat-model.md` for what is and is not in scope.

A bypass of a shipped rule that the threat model says should be caught is a
vulnerability. Report it privately through GitHub's "Report a vulnerability"
button on the Security tab of this repository. Please do not open a public
issue for a bypass.

Targets: acknowledgement within 72 hours, triage within 7 days, fix or
mitigation within 30 days.
